# Guide de Publication - Horizon Bilingue

## 🚀 Préparer votre application pour la publication

Votre application Horizon Bilingue est maintenant prête à être publiée sur les app stores ! Suivez ce guide pour générer les builds et publier votre application.

---

## 📱 Publication sur Google Play Store (Android)

### Étape 1 : Générer le build APK/AAB

1. **Cliquez sur le bouton "Publier"** dans l'interface Manus (en haut à droite du Management UI)
2. **Sélectionnez "Android"** comme plateforme
3. **Attendez la génération** du fichier APK (cela peut prendre 5-10 minutes)
4. **Téléchargez l'APK** généré

### Étape 2 : Créer un compte Google Play Console

1. Allez sur [Google Play Console](https://play.google.com/console)
2. Créez un compte développeur (frais uniques de $25)
3. Créez une nouvelle application

### Étape 3 : Configurer votre application

1. **Informations de base** :
   - Nom : Horizon Bilingue
   - Description : Une application ludique pour apprendre l'alphabet arabe en 30 jours
   - Catégorie : Éducation
   - Contenu : Enfants (7+)

2. **Captures d'écran** : Uploadez au moins 2 captures d'écran de votre application

3. **Icône** : Utilisez l'icône fournie (assets/images/icon.png)

### Étape 4 : Uploader le build

1. Allez dans **Gestion des versions → Production**
2. Créez une nouvelle version
3. Uploadez le fichier AAB généré
4. Remplissez les notes de version

### Étape 5 : Soumettre pour examen

1. Vérifiez tous les détails
2. Cliquez sur **Soumettre pour examen**
3. Attendez l'approbation (généralement 24-48 heures)

---

## 🍎 Publication sur Apple App Store (iOS)

### Étape 1 : Générer le build IPA

1. **Cliquez sur le bouton "Publier"** dans l'interface Manus
2. **Sélectionnez "iOS"** comme plateforme
3. **Attendez la génération** du fichier IPA (cela peut prendre 10-15 minutes)
4. **Téléchargez l'IPA** généré

### Étape 2 : Créer un compte Apple Developer

1. Allez sur [Apple Developer Program](https://developer.apple.com/programs/)
2. Enregistrez-vous en tant que développeur (frais annuels de $99)
3. Acceptez les accords de licence

### Étape 3 : Configurer votre application

1. Allez sur [App Store Connect](https://appstoreconnect.apple.com)
2. Créez une nouvelle application
3. Remplissez les informations :
   - Nom : Horizon Bilingue
   - Description : Une application ludique pour apprendre l'alphabet arabe en 30 jours
   - Catégorie : Éducation
   - Classification du contenu : 4+

### Étape 4 : Uploader le build

1. Utilisez **Xcode** ou **Transporter** pour uploader l'IPA
2. Attendez la validation automatique

### Étape 5 : Soumettre pour examen

1. Remplissez les informations de test
2. Acceptez les conditions de contenu
3. Cliquez sur **Soumettre pour examen**
4. Attendez l'approbation (généralement 24-48 heures)

## 🎯 Conseils pour une meilleure approbation

1. **Clarté** : Expliquez clairement ce que fait votre application
2. **Contenu** : Assurez-vous que tout le contenu est approprié pour les enfants
3. **Confidentialité** : Soyez transparent sur la collecte de données
4. **Qualité** : Testez complètement avant de soumettre
5. **Icônes** : Utilisez des icônes claires et attrayantes
